1. PROJECT OVERVIEW
-------------------------------------------------------------------------------
FoodyFi is an AI-powered smart cooking assistant web application built using 
Django (Python backend), MongoDB Atlas (User Storage), OpenAI (GPT-4o / Vision API 
for Recipe Generation & Ingredient Detection), and Vanilla JS / CSS (Modern 
Glassmorphism Web UI).

Key Highlights:
 - AI Recipe Generation in English, Kannada (ಕನ್ನಡ), and Hindi (हिंदी).
 - Detailed 6-8 step cooking instructions with flame levels and timings.
 - MongoDB Atlas user registration, password hashing, and session login.
 - Dual-Engine Multilingual Voice Assistant (Text-To-Speech) for Kannada, Hindi & English.
 - Hands-Free Voice Commands for kitchen navigation ("Next", "Back", "Listen").
 - AI Vision ingredient detection from photo uploads.

4. USER AUTHENTICATION & PAGE ACCESS FLOW
-------------------------------------------------------------------------------
 - Mandatory Access Sequence:
     1. User Registration (/register/)
     2. User Login (/login/)
     3. Full Access to Application Pages

 - Registration View (/register/):
   Captures Full Name, Username, Email, and Password. Creates hashed user record in 
   MongoDB Atlas, displays success toast message, and redirects to Login page.

 - Login View (/login/):
   Authenticates credentials against MongoDB Atlas hashed passwords. Sets session 
   state (request.session['mongo_user']) and redirects user to Homepage.

 - Protected Routes (@login_required_custom):
   /                    (Home Generator)
   /search/             (Recipe Search)
   /generate/           (AI Recipe Creation)
   /recipe/<id>/        (Recipe Detail)
   /recipe/<id>/cooking/(Cooking Mode)
   /profile/            (User Profile Dashboard)


5. AI RECIPE & VISION SERVICES (recipes/ai_services.py)
-------------------------------------------------------------------------------
 - Ingredient Vision Detection (detect_ingredients_from_image):
   Receives uploaded photo bytes and uses OpenAI Vision API (GPT-4o-mini) to 
   identify ingredients with simulated fallback detection.

 - In-Detail AI Recipe Generator (generate_recipe_ai):
   Generates comprehensive, 6 to 8 step cooking instructions in English, Kannada, 
   or Hindi. Each step details:
     * Prep & knife-cut technique
     * Flame level (low, medium, high)
     * Exact timings in minutes
     * Spice ratios & aroma checkpoints
     * Final garnishing & serving pairings

 - AI Food Photography (generate_food_image_ai):
   Generates studio dish cover photography via OpenAI DALL-E 3 or Pollinations AI.


6. MULTILINGUAL VOICE ASSISTANT & COOKING MODE (recipes/templates/recipes/cooking_mode.html)
-------------------------------------------------------------------------------
 - Dual-Engine Speech System:
     Engine 1: Browser SpeechSynthesis (queries native voices kn-IN, hi-IN, en-US).
     Engine 2: Cloud Native Audio Stream Fallback (100% guaranteed working native 
               audio playback for Kannada, Hindi & English across all devices).

 - Multilingual Hands-Free Voice Commands:
     Listens via Web Speech Recognition API matching selected recipe language:
     * English: "next", "back", "listen", "stop"
     * Hindi: "आगे" / "अगला", "पीछे", "सुनो" / "पढ़ो", "रुको"
     * Kannada: "ಮುಂದೆ", "ಹಿಂದೆ", "ಓದು" / "ಕೇಳು", "ನಿಲ್ಲಿಸು"

 - Navigation Controls:
     * Previous Step: Disabled on Step 1, active on Step 2+. Moves back 1 step.
     * Next Step: Advances step by step; finishes cooking on final step.
     * Review Steps: Jump back from celebration screen to re-review instructions.
